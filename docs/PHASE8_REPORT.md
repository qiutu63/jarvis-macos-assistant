# Phase 8：本机语音唤醒

## 已实现

- 桌面快捷栏新增“唤”开关，默认关闭，用户主动点击后才启动麦克风监听。
- 唤醒短语为“贾维斯·零”。触发后进入已有连续语音会话；同一句中唤醒短语之后的转写会作为首条请求。
- 复用 Swift 辅助程序的 Apple SpeechAnalyzer 中文本机模型，不写入音频文件，不上传音频。
- 可再次点击关闭监听；应用退出时监听子进程随 Tauri 任务结束。

## 限制与待验收

- 这是连续本机语音转写后匹配短语，不是专用关键词识别模型。开启期间麦克风持续工作，可能比低功耗关键词模型耗电更多，也可能误识别。
- 中文 SpeechAnalyzer 模型需要可用并已安装；首次下载需用户确认。
- 代码已接入，尚需在目标 Mac 上检查授权提示、真实唤醒、误唤醒、唤醒后命令截取、停止及退出行为。

## 可靠性改进：监听启动状态

- 桌面端将唤醒监听区分为“正在启动”和“正在监听”。启动命令返回时不再提前显示监听就绪；只有 Swift 辅助程序确认音频引擎开始录音后，界面才进入“等待唤醒词”状态。
- 这样麦克风权限错误或辅助程序启动失败时，界面不会先显示已就绪。实际授权和设备行为仍需在目标 Mac 上验收。
