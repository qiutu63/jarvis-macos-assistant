# Phase 11：接入 Sherpa-ONNX 专用关键词检测

## 已完成

- 桌面快捷栏提供 `KWS` 按钮，可按需启动 Sherpa-ONNX 中文关键词检测；监听短语仍是“贾维斯·零”。默认不自动开启麦克风监听。
- “唤”按钮保留 Apple SpeechAnalyzer 识别方式；两种方式由用户显式选择，异常时可手动停止或切换。
- KWS 命中后将最多 12 秒的 16 kHz 单声道音频保存在进程内存中，静音 1 秒后提交识别，最长等待 8 秒；不写音频文件。
- 用户已运行 `scripts/run_kws_candidate.command` 并看到 `WAKE_WORD_DETECTED:贾维斯零` 输出，确认候选检测器能命中短语。该终端候选验证不代表桌面同句命令交接、启动后自动监听或资源占用已验收。

## 验收范围

- 已完成桌面构建验证；真实日常使用和资源占用仍需观察。
- KWS 使用专用关键词模型；本阶段没有采集或对比 CPU、能耗数值，也没有把它设置为启动默认项。
- 保留 ASR 回退按钮；如果 KWS 监听异常，可以点“唤”切回旧模式。

## 建议观察

- 冷启动后是否进入 KWS 等待状态。
- “贾维斯·零，……”同句命令是否完整进入对话。
- 说“退下吧”后是否自动恢复 KWS 等待状态。
- 使用 Activity Monitor 比较安静监听 3–5 分钟时 JARVIS 子进程的 CPU 占用。
