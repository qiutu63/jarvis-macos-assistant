# Phase 2 实现与离线验收记录

日期：2026-10-08（Asia/Shanghai）

## 已实现

- `list_workspace`、`read_workspace_file`、`write_workspace_file`：工作根目录固定为 `~/JARVIS_Workspace`。仅接受相对路径；拒绝空路径组件、绝对路径、反斜杠、`..` 和经过符号链接的目录项。读取上限 100 KB，仅 UTF-8 普通文件；写入上限 100 KB，在目标目录以权限 600 的临时文件原子替换。
- `open_application`：只允许 Finder、Calculator、Notes、Safari、TextEdit，调用固定的 macOS `/usr/bin/open -a`。
- `run_terminal`：只允许 `python_version`、`node_version`、`git_status`。进程以固定 argv 启动，不经 Shell；工作目录固定为工作区根目录，不接受路径参数。
- 目录列举、文件读取/写入、应用启动和终端操作均设为 `CONFIRM`。CLI 在本机确认后执行；拒绝、EOF 或无确认回调时 fail closed。CLI 输出不含工具参数的确认结果审计行。
- 设置强制限制工作目录为 `~/JARVIS_Workspace`，拒绝工作目录本身为符号链接。

## 安全限制

没有任意 Shell、自由命令参数、管道、重定向、脚本或模型生成代码执行功能。白名单不是通用终端的替代品。所有文件路径都由工具代码验证，不接受模型提供的工作区外绝对路径。

## 验收

本阶段通过项目离线测试集验证路径穿越/符号链接拒绝、文件原子读写、工具白名单与确认拒绝。工作区目录延迟到用户首次确认文件或终端操作后创建。没有启动真实应用、写入用户工作区文件或执行用户系统命令。真实 LLM 如何选择并调用这些工具仍需后续真实模型端到端联调。
