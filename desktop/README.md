# JARVIS Desktop Pet

JARVIS 的 macOS 桌面伙伴界面，使用 Tauri 2、Vue 3 和 TypeScript。界面通过本机 JSON Lines bridge 调用项目根目录中的 Python Agent；不开放本机网络端口。

## 开发

先在项目根目录准备 `.venv`、模型配置和 Python 依赖，再运行：

```bash
cd desktop
npm install
npm run tauri dev
```

仅构建前端：

```bash
npm run build
```

## 界面行为

- 点击伙伴或快捷栏图标展开对话、记忆面板。
- 伙伴、气泡、对话面板、快捷栏和拖动把手可交互；窗口其余透明区域会把鼠标事件交给桌面下方的应用。
- 工具需要确认时，对话会停留在确认卡片；此时不能切换到记忆面板。
- “清空本次显示”仅清理窗口里的消息；记忆面板中的“清除”会删除本机 SQLite 短期历史。
- 按住伙伴下方右侧的“按住拖动”把手移动窗口；点击伙伴用于展开/收起面板。
- 点击语音按钮进入连续对话；每句话停顿约 1.5 秒后自动识别并发送，JARVIS 朗读回答后继续聆听，再次点击结束。首次使用会询问是否从 Apple 下载本机识别模型。
- 模型回复默认由 macOS 本机高品质中文语音自动朗读；快捷栏扬声器按钮可关闭或重新开启自动朗读。朗读会稍微放慢语速并保留句间停顿。
- 连续对话期间始终语音回答，并等朗读结束后才重新打开麦克风，避免把自己的声音识别为用户输入。
- “唤”按钮使用 Apple SpeechAnalyzer 本机转写并匹配“贾维斯·零”；`KWS` 按钮使用 Sherpa-ONNX 专用关键词检测。两种监听均由用户主动开启，聊天面板不会因唤醒自动展开。
- 宠物立绘会依应用状态轻微浮动、呼吸或倾斜，并遵循系统减少动态效果偏好；原有 PNG 素材和界面布局保持不变。
- Python Agent、Provider 和已配置的 MCP stdio 服务在桌面进程生命周期内复用；每个 MCP 工具调用仍需确认。
- 朗读时会跳过 Markdown 标记、代码块和链接地址，避免把排版符号逐个念出来。

项目说明、隐私边界和已知限制见根目录的 `README.md` 与 `docs/PHASE7_REPORT.md`。

当前 macOS 构建依赖工程根目录中的 Python 环境、用户配置及语音资源，生成的 `.app`/`.dmg` 尚不能作为独立安装包分发。
